# Model card — Đường An VN demo passability engine

**Version**: `demo-<spec_hash>` (spec hash printed by `/v1/model-card`)
**Date**: 2026-08-20 · **Status**: hackathon demo (not an operational service)

## What this model is
A physics-prior ensemble state estimator over the Thủ Đức road/alley graph
(25,809 directed edges from OpenStreetMap), producing per-edge water-depth
distributions and vehicle-specific passability probabilities for a **simulated**
compound rain–tide event, with observation assimilation from **simulated** feeds
(OSSE design: observations are drawn from a designated truth run through per-source
noise models — the assimilation code path is production-shaped; only the sensors are fake).

## What this model is NOT
- Not trained or validated on any real flood observation.
- Not a guarantee of safety anywhere, ever. Lower risk ≠ no risk.
- Not an operational forecast for Thủ Đức. All map states carry `is_synthetic: true`.

## Vehicle envelopes (conservative, hand-authored)
Sources: public manufacturer guidance on wading/fording depth, agency flood-driving
guidance (e.g. "turn around, don't drown" ~15 cm moving water for cars), with safety
margins. Never learned from user attempts. To be replaced by controlled-track
measurement + expert review before any pilot (proposal C4).

| Vehicle | Caution (cm) | Refuse (cm) | Note |
|---|---|---|---|
| motorbike | 10 | 20 | exhaust/air intake, balance in wake waves |
| e-2-wheeler | 8 | 15 | battery/controller exposure — strictest |
| small car | 15 | 25 | air intake; door sill ingress |
| emergency (authorized) | 25 | 40 | operator override permitted, logged |

## Safety policy implemented (invariants I1–I7, property-tested)
uncertainty never renders as safety; staleness only raises risk; official closures
override the model instantly (π := 0); consumer routing never *recommends* an edge
beyond the envelope; unknown stays visible and expensive to route through; raw
imagery never reaches the server (client-side 64×64 blur only).

## Physics guards (run-time counters, exposed at /v1/ops/feeds)
negative-depth clamps: 0 · uphill-flow violations: impossible by construction ·
temporal jump warnings: 0 (final calibrated run)

## Known limitations
1. GLO-30 (30 m) elevation cannot resolve curbs, alley microtopography, or underpasses.
2. Drainage capacity κ is a latent prior (road class + sink score), not measured pipe data.
3. Flow velocity is not modelled; moving-water hazard is handled only by conservative envelopes.
4. Single simulated storm; no cross-event or cross-city validation is claimed.
5. The replay benchmark's CI is an OD-level bootstrap over ONE simulated event —
   it is not the storm-block CI the six-month pilot pre-registers.

## Measured performance (frozen build)
Route request p50 364 ms / p95 1.84 s (n=200 random OD, mixed ticks — G3.5/G8.5 PASS).
