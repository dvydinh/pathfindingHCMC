# Data in this artifact

Two kinds of file live here, split by one question: **can it be regenerated byte-for-byte?**

## Shipped (1.8 MB)

Small, and expensive or impossible to refetch identically because the upstream source
changes under you. OpenStreetMap is edited continuously and Open-Meteo forecasts move
hourly, so a rerun of the fetch scripts next month will legitimately produce *different*
files. These copies are what the reported numbers were measured against.

| Path | What | Source |
|---|---|---|
| `derived/{scene}_places.json` | Street + landmark gazetteer | OSM (ODbL) |
| `derived/{scene}_edge_names.json` | `way_id -> street name` | OSM (ODbL) |
| `raw/{scene}.poi.json` | Named POIs and place nodes | OSM Overpass (ODbL) |
| `raw/{scene}.env.json` | Temperature, humidity, PM2.5/PM10, dust, AQI, UV | Open-Meteo (CC-BY 4.0) |
| `raw/{scene}.charging.json` | EV charging stations, bbox + 12 km buffer | OSM Overpass (ODbL) |
| `eval/replay_metrics.json` | Matched-OD routing evaluation output | this work |

`CHECKSUMS` covers every file above.

## Not shipped, rebuilt instead (~670 MB)

| What | Size | Why it is not here |
|---|---|---|
| `{scene}.osm.json`, GLO-30 tile | ~50 MB | Refetchable; large; licences prefer you fetch from source |
| `{scene}_edges.json` | 25 MB | Deterministic output of `build_graph.py` + `attach_terrain.py` |
| Scenario `.npz`, `_ens.npy`, quantile parquet | ~590 MB | **Content-addressed and deterministic**: the same spec and seed produce identical bytes (gate G2.1), so shipping them adds size without adding trust |

`bash ../reproduce.sh` rebuilds all of it.

## Honest limits of this data

- **Ambient resolution is coarser than the scene.** Open-Meteo resolves to ~8-11 km cells;
  the Thu Duc bbox is 6.6 km across and is covered by four of them. The layer renders
  blocks and states its own resolution rather than interpolating a smooth field.
- **No EV charging is mapped inside either demo bbox.** Nearest is 7.5 km east of the Thu
  Duc centre. Hanoi has ~310 stations and HCMC 19, so this is an OSM coverage gap in these
  two areas, not evidence that nowhere charges. No pin was invented to fill it.
- **Flood state is simulated.** Every dynamic flood value carries `is_synthetic: true`.
  The ambient layer is the one exception and is labelled `observed`.
